## Что нужно сделать для релиза 2.0

Скриншоты 2.0 снимаются с устройства/эмулятора (1080×1920) и должны показывать новую игру:

1. Карта городка с жителями, плашкой события дня и шапкой (монеты/силы/осколки).
2. Вкладка «Жители»: карточка жителя с полосой доверия, ступенью дружбы и шагом истории.
3. Вкладка «Сумка»: предметы и мозаика городка (частично собранная — красивее).
4. Вкладка «Крафт»: рецепты и ингредиенты.
5. Вкладка «Дела»: дневные цели, заказы жителей, лоток торговца.
6. Вкладка «Город»: улучшения и достижения.
7. Диалог истории жителя (📖 в журнале) — как социальное доказательство.

Порядок установки:
```bash
gradle :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb exec-out screencap -p > assets/store/shot1_1080x1920.png
```
