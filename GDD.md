# GDD — «Пазл из Жизни» (Puzzle of Life)

## Хук
Cozy life-sim: NPC помнит игрока и друг друга, сплетничает, меняет тон после поступков.
«NPC помнит меня и рассказывает другим». 0:30 — запоминает имя; 5:00 — вспоминает прошлую сессию.

## Ядро петли
1. Прогулка по городку → встреча с NPC → действие/выбор реплики.
2. NPC меняет trust/mood, пишет событие в память.
3. Другие NPC сплетничают → мир «живёт».
4. Сессия сохраняется; следующая сессия начинается с вспоминания.

## NPC MVP (волна 1)
- Память: краткосрочная + долгосрочная, консолидация по важности.
- Характер: traits; эмоции: mood + intensity; trust к игроку −1..1.
- Отношения NPC↔NPC; расписание дня (место по часу).
- Gossip: реплики про игрока и про других NPC.
- Реакция на поступки: karma меняет trust и тон приветствия.

## Дальше (v1.1+)
- Больше NPC/мест, события, квесты, монетизация (косметика, без pay-to-win), LLM-диалоги (с AI-декларацией Play).

## Волна 4 — реализовано
- DialogueComposer: процедурные реплики (память + характер + место + настроение), без LLM.
- In-app report «Сообщить» (ReportService, user://reports.json) — требование Play для AI-контента.
- docs/PLAY_COMPLIANCE.md: API 36, AAB, signing, AI-декларация, Data Safety, рейтинг.
- CI .github/workflows/android-aab.yml: сборка AAB из тегов/пушей (keystore из Secrets).
