## 2025-05-18 - Jetpack Compose Composite Status Badges Semantics
**Learning:** In Jetpack Compose, compact status badges consisting of an emoji/icon and a numeric or formatted text value (e.g. `Row { Text("⏰"); Text(timeString) }` or `Row { Icon(Star); Text("$coins") }`) are announced by TalkBack as separate disjointed elements or raw numbers without context. Using `Modifier.semantics(mergeDescendants = true) { contentDescription = "..." }` on the parent container merges the badge into a single accessibility node with a clear, descriptive context (e.g., "Время: День 1, 08:00" and "Монеты: 25").
**Action:** Always apply `Modifier.semantics(mergeDescendants = true)` with a descriptive `contentDescription` on composite status pill and badge rows to ensure clear, non-fragmented TalkBack screen reader announcements.
