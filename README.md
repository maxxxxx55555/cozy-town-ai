# Пазл из Жизни (Cozy Town) 2.0

Уютный симулятор городка у реки с живыми жителями, памятью, сплетнями и мозаикой-пазлом.
Android, Kotlin + Jetpack Compose, **полностью офлайн**.

> «Жители помнят тебя и рассказывают друг другу о твоих поступках.»

## Что в игре

- **6 жителей с характерами**: Марта (пекарь), Борис (мастер), Лука (рыбак), Аня (цветочница), Осип (старый моряк), Соня (непоседа) — у каждого своё расписание, портрет, любимые подарки и **история из 4 частей**.
- **Память NPC**: они запоминают твоё имя и поступки, помнят события прошлых сессий, а при встрече передают новости друг другу (сплетни теряют в важности при передаче — как в жизни).
- **Живой городок**: 9 мест (пекарня, рынок, мастерская, площадь, таверна, причал, сад, маяк, дом), которые ходят по расписанию и меняют настроение.
- **Действия**: собрать ресурсы, поговорить, помочь, подарить, готовить (крафт), выполнять заказы, продавать, обустраивать город.
- **Прогресс**: уровень и опыт, силы (энергия действий), монеты, доверие жителей (4 ступени дружбы), серия возвращений (streak).
- **Петля возврата**: каждый игровой день — 3 новых дневных цели, 3 новых заказа жителей, новое событие дня (базар, дождь, праздник фонариков, рыжий кот, торговец, шторм).
- **Мозаика городка**: осколки собираются за заказы, истории, достижения и улучшения — 60 осколков складываются в картину городка (финал).
- **28 достижений**, 12 улучшений (от фонариков до маяка), 8 рецептов, 22 предмета.
- **Офлайн-забота**: пока тебя не было, жители вспоминают тебя, восстанавливаются силы, друг может оставить подарок.

## Управление

| Экран | Что делать |
|---|---|
| **Карта** | тап по жителю → поговорить, тап по месту → перейти туда; кнопка «Собрать» — ресурсы |
| **Жители** | поговорить / помочь / подарить, следить за доверием и двигать личные истории |
| **Сумка** | предметы, продажа, мозаика городка |
| **Крафт** | готовить вещи (дороже и желаннее для подарков) |
| **Дела** | цели дня, заказы жителей, лоток торговца |
| **Город** | улучшения, достижения, статистика, музыка, данные, «Сообщить» |

## Сборка и запуск

```bash
# Android-студия: открыть папку проекта, запустить :app
# или из командной строки:
gradle :app:assembleDebug        # APK для устройства
gradle :app:testDebugUnitTest    # юнит-тесты чистой логики
```

Требования: JDK 21, Android SDK (API 36), Gradle 9.x. Игра не требует интернета и не имеет разрешений, кроме базовых.

## Тесты

Логика игры — чистая (без Android) и покрыта 30 тестами: старт и имя, перемещение и gating локаций,
энергия, крафт, подарки, сплетни, заказы, квесты, достижения, осколки, смена дня и streak,
сейв/загрузка, миграция старого сейва v2, детерминизм ГПСЧ, оффлайн-возврат, анти-спам разговоров
и полная симуляция трёх дней игры (баланс-прогон).

```bash
# 1) Обычный путь (Android/Gradle):
gradle :app:testDebugUnitTest

# 2) Без Android SDK — headless-прогон ядра (нужны JDK и kotlinc):
bash tools/harness/build_core.sh
# выводит PASS/FAIL по каждому тесту и строку BALANCE — снимок баланса
```

## CI

В `.github/workflows/` лежит устаревший workflow прототипа (Godot). Готовый workflow для Android-версии
лежит в `docs/ci/android.yml` — перенести в `.github/workflows/` может только аккаунт с правом
на изменение workflow-файлов (см. `docs/ci/README.md`).

## Структура

```
app/src/main/java/com/aistudio/cozytown/
  core/      — чистое ядро: GameEngine, контент (предметы, места, рецепты,
               апгрейды, квесты, достижения, события), ГПСЧ, сейв-кодек
  model/     — модели мира: NPC, память, характеры, расписания, инвентарь, часы
  storage/   — сейв на диск (JSON + SHA-256, .bak), отчёты
  ui/        — Compose: экран, карта городка, ViewModel, тема
  audio/     — музыка и SFX
app/src/test/  — общие тест-кейсы ядра (JUnit-обёртка + headless-раннер)
tools/harness/ — сборка и прогон ядра без Android/Gradle
docs/          — GDD, TZ, ASO, приватность, чек-лист релиза, прохождения
```

Сохранения — один файл `save.json` + бэкап, с контрольной суммой SHA-256 и миграцией старых версий
(сейв v1/v2 из первой версии игры подхватывается автоматически).
