# MONETIZATION — «Пазл из Жизни»

## Принцип
Cozy-симулятор без pay-to-win. Деньги не ломают «живой город»: память NPC и отношения — навсегда и только за честную игру.

## MVP (без IAP)
- Нет покупок, рекламы, микротранзакций. Блокер в том числе: приложение работает офлайн, `permissions/internet=false`.
- Монетизация откладывается до v1.1.

## v1.1 — IAP (косметика)
- Плагин: **GodotGooglePlayBilling v8.3.0+** (Godot 4.6+), Android v2 plugin system (AAR + Gradle). Custom Build = ON обязателен.
- Товары: скины мебели, темы интерфейса, смена причёски NPC, декорации города. Никаких влияний на trust/память/валюту.
- Прайс-поинты Google: 149 / 349 / 749 ₽ (проверить актуальные в Console).
- Чеки покупок: состояние покупки проверяется через Billing и кэшируется локально (acknowledge purchase), с защитой от повторной выдачи (receipt id + anti-cheat в SaveGame).
- Data Safety: покупка обрабатывается Google Play; приложение получает purchase token → в форме указать «Purchase history: collected for functionality» + периодичность purchase.
- Удаление данных/возврат — по правилам Google Play, без ручной обработки платежей в приложении.

## Риски
- IAP усложняет AAB/keystore-конвейер — вводить только после стабильного релиза без IAP.
- Отзывы: не продавать «NPC-память» как предмет покупки — только визуал.
