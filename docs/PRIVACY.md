# Политика конфиденциальности — «Пазл из Жизни» (шаблон для размещения)

**Версия:** 1.0 | **Действует с:** даты релиза

## 1. Какие данные есть в игре
- Имя игрока (вводится в первые секунды).
- Память NPC: события, поступки, отношения, эмоции — **только на вашем устройстве**.
- Прогресс: день, время, монеты, инвентарь, дневные цели.
- Жалобы, отправленные через кнопку «Сообщить» (хранятся локально, до 50 записей).

## 2. Куда данные передаются
**Никуда.** Вся память NPC и прогресс хранятся локально (внутреннее хранилище приложения, файлы `save.json` и `reports.json`). Приложение не требует разрешение INTERNET и не содержит аналитику и рекламу.

## 3. AI-контент
Диалоги NPC генерируются процедурно на устройстве из памяти и характера NPC (без облачной генерации). Если в будущих версиях появится облачная LLM-генерация текста, будет раскрыто в разделе AI-generated content в Google Play, а в игре — кнопка «Сообщить».

## 4. Удаление данных
Удаление приложения удаляет все данные. Внутри игры: сброс прогресса (функция будет добавлена в релизной версии) также удаляет сейв.

## 5. Дети
Приложение не собирает персональные данные и не показывает рекламу. Возрастной рейтинг: 3+/Everyone.

## 6. Контакты
Поддержка: EMAIL (указать перед релизом) · Жалобы: кнопка «Сообщить» в игре.

## 7. Play Data Safety (честная форма)
- Данные собираются: **Нет** (текущая версия, офлайн, без сети).
- Данные передаются: **Нет**.
- Сторонние SDK: **Нет** (Godot без плагинов; IAP не используется).
- Сброс: удаление приложения / данных.
